公共字段自动填充功能技术文档

1. 整体架构概述

公共字段自动填充功能是一个基于AOP（面向切面编程）的解决方案，用于在数据库操作时自动填充如创建时间、更新时间、创建人、更新人等公共字段。该功能通过自定义注解、切面编程和反射机制实现，避免在每个实体类的CRUD操作中重复编写相同的字段赋值代码。

2. 核心组件分析

2.1 自定义注解 - AutoFile

2.2 操作类型枚举 - OperationType

2.3 常量类 - AutoFillConstant

2.4 上下文工具类 - BaseContext

2.5 切面类 - AutoFileAspect

3. 实际应用示例

3.1 在Mapper中使用注解

3.2 实体类要求

4. 核心流程解析

4.1 自动填充流程图

4.2 详细步骤说明

  1. AOP切入
    • 定义切入点表达式，匹配所有在com.sky.mapper包下且标注了@AutoFile注解的方法
    • 使用@Before前置通知，在目标方法执行前进行拦截
  2. 获取操作类型
    • 通过反射获取方法上的@AutoFile注解
    • 获取注解中的OperationType值（INSERT或UPDATE）
  3. 获取实体对象
    • 从JoinPoint中获取方法参数
    • 取第一个参数作为需要填充的实体对象
  4. 获取填充数据
    • 从BaseContext中获取当前登录员工ID
    • 获取当前系统时间作为时间戳
  5. 反射设置字段值
    • 根据操作类型确定需要填充哪些字段
    • 使用反射机制调用实体类的setter方法
    • 设置对应字段的值

5. 关键特性

5.1 操作类型区分

  • INSERT操作：填充创建时间、更新时间、创建人、更新人四个字段
  • UPDATE操作：仅填充更新时间、更新人两个字段

5.2 反射机制

  • 通过反射动态调用实体类的setter方法
  • 不依赖具体的实体类类型，具有良好的通用性

5.3 线程安全

  • 使用ThreadLocal存储当前用户ID，确保线程安全
  • 每个线程都有独立的用户上下文

6. 使用约束

6.1 实体类要求

  1. 必须包含标准的setter方法（遵循JavaBean规范）
  2. 公共字段必须包括：
    • createTime: LocalDateTime类型
    • updateTime: LocalDateTime类型
    • createUser: Long类型
    • updateUser: Long类型

6.2 Mapper层要求

  1. 需要在需要自动填充的方法上添加@AutoFile注解
  2. 注解参数必须指定操作类型（INSERT或UPDATE）

7. 异常处理

7.1 异常类型

  • NoSuchMethodException: 实体类缺少对应的setter方法
  • IllegalAccessException: setter方法不可访问
  • InvocationTargetException: setter方法执行异常

7.2 异常处理策略

  • 捕获所有反射相关异常
  • 记录详细错误日志
  • 不中断主要业务流程

8. 优势分析

8.1 代码复用性

  • 避免在每个实体类的CRUD操作中重复编写字段填充代码
  • 一处定义，多处使用

8.2 维护性

  • 当需要修改公共字段规则时，只需修改切面类
  • 不需要修改业务代码

8.3 一致性

3. Cron表达式详解

Cron表达式由6或7个字段组成，格式如下：

常用符号含义：

  • : 匹配任意值
  • /: 步长，如0/5表示从0开始，每隔5个单位
  • ,: 列表，如1,3表示1和3
  • : 范围，如1-3表示1到3
  • ?: 不指定值，用于日和星期字段

系统中使用的表达式示例：

  • "0/5 * * * * ?": 每5秒执行一次
  • "0 */1 * * * ?": 每分钟执行一次
  • "0 0 1 * * ?": 每天凌晨1点执行一次

4. @Scheduled注解

主要属性

  • cron: 使用Cron表达式定义执行时间
  • fixedRate: 固定频率执行（毫秒）
  • fixedDelay: 固定延迟执行（毫秒）
  • initialDelay: 首次执行前的延迟时间

3. 任务幂等性

设计任务时要考虑幂等性，即使多次执行也不会产生副作用。
