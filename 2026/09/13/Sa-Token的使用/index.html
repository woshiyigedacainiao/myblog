八、登录时序总结

  1. 请求：POST /auth/login，body 为 {username, password}
  2. 参数校验：@Valid 拦截空值/长度，失败返回 400
  3. 锁定检查：Redis key auth:login:fail:{username} ≥ 5 则抛 ACCOUNT_LOCKED
  4. 身份校验：查库 + BCrypt.checkpw 比对密文，失败则 increment 计数并异步写失败日志
  5. 状态校验：status=0 禁用账号拒绝
  6. 登录成功：清除 Redis 失败计数 → StpUtil.login(userId) 生成 token → 异步写成功日志
  7. 返回：{ token, userInfo: { id, username, nickname, avatar, roles[], permissions[] } }
  8. 后续鉴权：请求头带 Authorization: Bearer {token}，SaInterceptor 校验登录态，@SaCheckRole/@SaCheckPermission 触发 StpInterfaceImpl 查库做权限校验

以上就是本项目登录认证的完整流程及对应代码。
