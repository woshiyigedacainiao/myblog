我的鉴权登录认证

发表于 2026-09-09

#hmall 项目完整登录认证鉴权流程

本项目采用 Spring Cloud Gateway + JWT(RS256) + ThreadLocal 的微服务统一鉴权方案。核心思路：网关统一验签，服务间通过请求头传递用户身份，各服务用 ThreadLocal 持有当前用户。

一、整体架构分层

模块 职责
hm-gateway 统一入口，校验 JWT、放行/拦截、透传用户信息
hm-common 公共组件：异常、UserContext、UserInfoInterceptor、自动配置
user-service 登录接口，生成 JWT
cart-service 等业务服务 通过 UserContext 获取当前用户，执行业务

五、关键设计要点

  1. 非对称签名 RS256：网关和 user-service 共用同一份 hmall.jks 密钥对，user-service 私钥签发，网关公钥验签（实际都用 KeyPair，含公私钥）。
  2. 网关只做验签：下游服务不再解析 JWT，性能好且逻辑统一；用户身份通过 user-info 请求头透传。
  3. 白名单机制：AuthProperties.excludePaths + AntPathMatcher 控制无需鉴权的路径。
  4. ThreadLocal 用户上下文：UserContext 让业务层无感获取当前用户，请求结束自动清理。
  5. 统一异常：UnauthorizedException(401)、ForbiddenException(403)、BadRequestException(400) 等在 hm-common 定义，由 CommonExceptionAdvice 统一处理。
